# Лабораторная работа 1

В данной папке содержатся результаты выполнения первой лабораторной работы:
* `ratings.csv` — файл с оценками пользователей (содержит столбцы: userId, movieId, rating, timestamp).
* `ratings_count.txt` — результаты подсчета минимального и максимального userId и количества строк для них.
* `sqlite.txt` — информация о версии установленной СУБД SQLite и доступных режимах вывода данных.
